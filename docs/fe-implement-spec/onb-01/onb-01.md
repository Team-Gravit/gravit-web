로그인은 됐지만 계정이 아직 없는 사용자가 프로필 색과 닉네임을 정해 가입을 마친다.

> **이 화면은 로그인 흐름의 마지막 단계다.** 좁은 화면 상단바 제목이 「로그인」인 것은
> 오기가 아니라 제품이 이 흐름 전체를 그렇게 부르기 때문이다.

> `ONB-01/A`~`/C` 는 별개 화면이 아니라 같은 화면의 **상태 변형**이다. 같은 글자가 플랫폼마다
> 다른 상태를 가리키므로 (WEB `/B`=유효 / MOB `/B`=형식 오류) 아래 §3 은 상태 이름으로 적는다.

## 4. 라우트 및 화면 이동

```
OAuth 콜백 (isOnboarded === false)
  └─ /onboarding
       ├─ 「다음」 성공 → /onboarding/success
       └─ 취소(좁은 화면) → 세션 삭제 → /
```

넓은 화면에는 취소 수단이 없다. **브라우저 백은 가로채지 않는다** — 백은 「이전 화면」이지
「취소」가 아니라서, 실수로 누른 사용자를 로그아웃시키게 된다. 콜백이 `replace` 로 이동하므로
백을 누르면 외부 인가 페이지로 나가고, 인증·온보딩 게이트(`MIG-005` Issue 4)가 제자리로 돌린다.
