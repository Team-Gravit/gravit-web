# Colors

`app/styles/tokens.css`의 `@theme static`에 정의된 color 토큰입니다.
값의 단일 소스는 `tokens.css`입니다.

> 컴포넌트에서는 hex를 하드코딩하지 말고 `bg-main`, `bg-bg-1`, `text-text-1`, `border-divider-1`처럼 토큰 기반 Tailwind class를 사용합니다.
