# FIX-077 — 리그 모바일 배경을 그라데이션과 장식이 함께 늘어나게

GitHub Issue: #380 (FIX-073 `checklist.md` 「남은 것」에서 분리)

## 배경 · 목표

리그 모바일(768px 미만) 배경은 그라데이션이 화면 전체에, 투명 장식은 `object-cover`로 따로 늘어나 화면 폭이 시안(360)과 다르면 둘이 어긋난다. 장식도 1배(360×692)라 고해상도 폰에서 흐리다. 메인 히어로 · 학습 카드처럼 둘을 한 상자에 넣어 함께 늘리고, 장식을 시안에서 2배로 다시 받는다.

## 범위

- `pages/league/ui/league-page.tsx` `LeagueBackground` 좁은 화면 · `assets/league-bg-mobile.png`
- 공용 캔버스 `shared/ui/gradient-canvas`를 그대로 쓴다(새 prop 없음 예정)

## Out of Scope

- 리그 데스크톱 배경 — #378에서 시안과 같음(0.027%)을 확인했다
- 리그 덮개 · 그라데이션 값의 데스크톱 쪽
- 배경을 화면에 고정하는 방식 변경 — 리그는 이미 `fixed`다. 다른 화면은 FIX-076

## 시안 · 에셋 (2026-11-03)

- 시안: 사용자가 콘텐츠를 뺀 `LG-01-MOB` 배경 프레임 `16060:14084`(360×692)를 새로 만들었다. 프레임 채우기가 그라데이션이다
- 그라데이션(360×692 상자 기준): `linear-gradient(282.21deg, #4721CA 3.59%, #17034E 95.08%)` — Figma `cssAngle`과 같다. 지금 코드는 740 높이 기준 `281.43deg`
- 장식: 프레임 복제본에서 채우기만 지워 2배(720×1384) 투명 PNG로 내보내고 복제본은 지웠다(원본 프레임 미변경). CSS 그라데이션 위에 얹으면 원본과 최대 4/255 · 8/255 넘는 픽셀 0%. webp 약 46 KB(지금 1배 18 KB)
- 지금 1배 PNG도 같은 그림이다(2배 시안과 0.56% — 1배를 키운 경계 차이)

## 확정 명세 · 검증 기준

GitHub #380의 AC-1 ~ AC-3. 픽셀 기준은 「8/255 넘게 다른 픽셀 0.1% 이하」(`image-convention.md` §6).
