# REF-063 — 첫 청크 추가 축소 — 퀴즈 코드와 아이콘

GitHub Issue: #312 (관련 #299 · PR #311 · REF-062 #313)

## 배경 · 목표

#299에서 마크다운을 분리해 첫 청크(`index-*.js`)를 861KB → 630KB(gzip 276KB → 200KB)로 줄였다.
남은 첫 청크에도 첫 화면에서 쓰지 않는 코드가 들어 있다. **퀴즈 코드**와 **쓰지 않는 아이콘**을 첫 청크에서 빼고,
모든 화면의 첫 그리기(FCP)가 줄어드는지 측정으로 확인한다.

근거: `local-docs/performance/evidence/2026-10-20_299-markdown-lazy/` (로컬 전용) · 번들 지도 `2026-10-18_bundle_visualizer_lazy-markdown.html`

## 현행 기준선 (2026-10-20, #299 적용 후 첫 청크)

번들 지도의 모듈별 비율(압축 전 크기는 실제 파일보다 크므로 비율로 본다).

| 묶음                                                                                                      | 첫 청크 안 비율 | 판단                                                |
| --------------------------------------------------------------------------------------------------------- | --------------- | --------------------------------------------------- |
| react-dom                                                                                                 | 약 36%          | 필수                                                |
| axios                                                                                                     | 약 14%          | 범위 밖 (인증·401 처리가 인터셉터에 있어 별도 검토) |
| TanStack Router·Query                                                                                     | 약 12%          | 필수                                                |
| **아이콘 SVG 90개** (`shared/ui/icon/assets`)                                                             | **약 11%**      | **대상**                                            |
| **퀴즈 코드** (`widgets/quiz-screen` · `features/lesson-quiz` · `entities/problem` · `pages/review-quiz`) | **약 5%**       | **대상**                                            |
| tailwind-merge                                                                                            | 약 4%           | 필수 (`cn()`)                                       |
| 로고 SVG                                                                                                  | 약 3%           | 첫 화면 사용 — 범위 밖                              |

### 퀴즈 코드가 들어오는 경로

#299의 마크다운과 같은 경로다. `autoCodeSplitting`은 라우트 설정을 첫 청크에 남긴다.

```text
learning.units.$unitId.{bookmarked,incorrect}-problems.tsx (라우트 설정)
 └ -review-quiz-route.ts
    ├ @/features/lesson-quiz   ← clearStoredQuizSession 하나
    ├ @/pages/review-quiz      ← toReviewQuizSessionKey 하나
    └ @/entities/problem       ← getReviewProblemsQueryKey 하나
```

### 아이콘이 모두 들어오는 이유

`shared/ui/icon/icons.generated.ts`가 SVG 90개를 모두 import해 `ICONS` 객체에 담고, `<Icon name="…" />`가 이름 문자열로 꺼낸다.
빌드 도구는 어떤 이름이 쓰일지 알 수 없어 90개를 모두 첫 청크에 넣는다.

- 소스(`*.stories` · `*.test` 제외)에서 이름 문자열로 쓰이는 아이콘은 **18개**, 쓰이지 않는 아이콘은 **72개** (2026-10-20 집계, 템플릿 문자열로 만든 이름은 없음)
- `stories/Iconography.mdx`가 `ICONS` 전체를 디자인 시스템 목록으로 보여 준다 — 아이콘 세트 자체를 줄이는 것은 디자인 시스템 결정이다

## 범위

- 라우트 설정이 퀴즈 코드를 첫 청크로 끌고 오지 않게 한다
- 아이콘이 첫 청크에 실리는 방식을 바꾼다 (아래 확인 필요 1)
- 전후 측정: 첫 청크 크기 · `/main` · `/learning` · 개념 노트 FCP·LCP (녹화 응답 재생 5회, 같은 빌드 재측정을 흔들림 기준으로)

## Out of Scope

- axios → fetch 전환 · 로고 · tailwind-merge
- 라우트 데이터 미리 요청 (REF-062) · 이미지 로딩 (REF-054)
- 아이콘 디자인·이름 변경

## 결정 (2026-10-24 사용자)

1. **아이콘은 아이콘별 import** — `Icon`은 유지하고 `name` 대신 아이콘 컴포넌트(`icon={BellIcon}`)를 받는다. 전체 목록은 Storybook 전용 `icon-catalog.generated.ts`로 분리한다.
   기각: SVG 72개 삭제(디자인 시스템 결정) · 스프라이트(받는 양 그대로, 첫 화면 아이콘 지연) · 사용 아이콘만 생성(숨은 재생성 단계)
2. **퀴즈 경로는 함수 이동** — `toReviewQuizSessionKey`를 `pages/review-quiz/model/`로 옮기고 같은 `index.ts`로 공개한다.
   기각: `sideEffects` 선언(단독 −0.5KB) · 지연 로딩(원인이 파일 위치라 불필요). 실험 근거는 `plan.md` §1
3. 착수 — #311 · #321 머지 후 `develop` `4fb2c6b5`에서 분기

## 결과 (2026-10-25)

### 첫 청크 `index-*.js`

| 빌드                | 원본                     | gzip                    |
| ------------------- | ------------------------ | ----------------------- |
| 현행 `develop`      | 629,881 B                | 200,597 B               |
| 커밋 1 (퀴즈 경로)  | 592,034 B (−37.8KB)      | 188,893 B (−11.7KB)     |
| 커밋 1+2 (+ 아이콘) | **516,079 B (−113.8KB)** | **170,829 B (−29.8KB)** |

- 첫 청크에서 안 쓰는 아이콘(`bell-off` · `calendar-remove` · `bar-left`)의 path가 사라지고 쓰는 아이콘은 남는다 (빌드 결과물 검색)
- 퀴즈 세션 context(`features/lesson-quiz`의 `QuizSessionProvider`) 모듈은 남는다. 라우트 설정이 같은 배럴에서 `clearStoredQuizSession`을 가져오고, `createContext` 호출이 부수 효과로 판단되기 때문이다. 약 5KB — `sideEffects` 선언만 덜어 낸다 (범위 밖)

### FCP · LCP (녹화 응답 재생 · CPU 4x · Fast 4G · 번갈아 5회 중앙값)

| 화면        | FCP 현행 → 최종 | LCP 현행 → 최종 | 흔들림 FCP · LCP |
| ----------- | --------------- | --------------- | ---------------- |
| `/main`     | 4.31 → 4.30s    | 4.31 → 4.30s    | 0.10 · 0.10s     |
| `/learning` | 3.81 → 3.85s    | 5.30 → 5.40s    | 0.23 · 0.30s     |
| 개념 노트   | 3.68 → 3.69s    | 8.73 → 8.09s    | 0.03 · 0.44s     |

흔들림 = 최종 빌드를 다른 포트에서 다시 잰 차이. 커밋 1 단독 빌드도 같은 범위 안이었다.

- **FCP · LCP 모두 흔들림 안 — 차이 없음.** 나빠진 화면도 없다. 개념 노트 LCP −0.64s는 흔들림(0.44s)보다 크지만, 같은 화면에서 빌드 간 편차가 커서 개선으로 보지 않는다
- 이 조건(대역폭 약 1MB/s)에서 gzip 30KB는 전송 약 0.03s다. JS 파싱 비용도 줄지만 첫 그리기를 정하는 요인이 아니었다. 효과는 받는 양 · 파싱 양 감소로 남긴다
- `/main` CLS는 회차마다 0.018 ~ 0.53으로 바뀐다 — 모든 빌드에서 같아 이번 변경과 무관하다 (기존 문제)
- 60회 모두 녹화에 없는 요청 0 · 렌더 글꼴 Pretendard
