### 실제 화면 확인 (headless Chrome + CDP, MSW)

배경은 6축 대조로 잡히지 않아 화면을 띄워 확인했다. 그 과정에서 배경 요소가 뷰포트보다
헤더 높이(112px)만큼 짧아 화면 아래가 비는 것을 발견해 고쳤다 — `min-h-full`의 `100%`가
스크롤 컨테이너의 content box 기준으로 풀린 탓이다. `SpaceBackground`의 `min-h-svh`를 그대로 둔다.

본문 컬럼 좌표를 폭별로 실측했다.

| 뷰포트 | 콘텐츠 x | 폭   |
| ------ | -------- | ---- |
| 800    | 32       | 736  |
| 1000   | 32       | 936  |
| 1264   | 32       | 1200 |
| 1280   | 40       | 1200 |
| 1440   | 120      | 1200 |
| 1920   | **360**  | 1200 |

1920에서 시안(`13752:84096` 카드 x=360 · w=1200)과 일치하고, 어느 폭에서도 폭이 튀지 않는다.
`default` variant(로그인·온보딩·모달)는 `bg-cover bg-center` 그대로임을 로그인 화면으로 확인했다.
