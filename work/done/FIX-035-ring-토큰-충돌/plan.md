# FIX-035 구현 계획

## 작업 종류

`FIX` — 미사용 숫자 색상 토큰이 Tailwind의 `ring-3` 두께 유틸리티를 색상 유틸리티로
오인하게 만들어 키보드 포커스 링이 사라지는 전역 스타일 버그를 수정한다.

## 영향 파일

| 구분 | 파일                                                   | 변경                                                  |
| ---- | ------------------------------------------------------ | ----------------------------------------------------- |
| 수정 | `apps/web/src/app/styles/tokens.css`                   | 미사용 `--color-3` 선언과 구역 주석 제거              |
| 수정 | `docs/design-system/README.md`                         | 정리 대상 토큰 대장에서 번호 토큰 행 제거, 합계 51→50 |
| 생성 | `work/in-progress/FIX-035-ring-토큰-충돌/checklist.md` | 자동 검사와 CSS 산출물 검증 결과 기록                 |

`ring-3` 사용 컴포넌트는 변경하지 않는다. 충돌 토큰만 제거해 Tailwind 표준 3px ring 두께가
복원되도록 한다.

## 구현 순서

- [x] `[app/styles]` `tokens.css`에서 `--color-3`과 불필요해진 「번호 색상」 주석 제거
- [x] `[docs]` 디자인 토큰 부채 대장에서 해당 행을 제거하고 합계를 50으로 갱신
- [x] `[검증]` `apps/web`에 `--color-3` 선언·사용이 남지 않았는지 검색
- [x] `[검증]` 웹 빌드 CSS에서 `ring-3`이 3px ring shadow를 생성하고 보라색 ring 토큰이 유지되는지 확인
- [x] `[검증]` lint·타입·테스트·빌드와 키보드 포커스 동작 확인
