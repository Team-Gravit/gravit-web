## 6. 중간에 막혔던 지점 — 스킬에 반영할 것

- **측정 환경이 결론을 뒤집었다.** 배터리 전원 · 측정 중 다른 작업 · 메모리 압박이 겹치면 같은 빌드도 ±1s 흔들려, 두 번의 측정이 Issue 2에 대해
  반대 결론을 냈다. 전원 연결 · 프로그램 종료 · 측정 중 작업 없음으로 다시 재서 판정했다.
  → 성능 측정 절차에 "전원 연결 확인(`Win32_Battery.BatteryStatus` = 2), 측정 중 다른 작업 금지, 기준 빌드와 번갈아 측정"을 넣는다.
- **날짜가 다른 단독 측정끼리 비교하면 안 된다.** 바꾸지 않은 로그인 화면도 0.38s 차이가 났다.
- **Git Bash가 `/main` 같은 인자를 Windows 경로로 바꾼다.** 측정 스크립트에 경로를 인자로 넘길 때 `MSYS_NO_PATHCONV=1`이 필요하다.
- **요청을 한꺼번에 앞당기면 서로 밀린다.** Issue 2에서 사용자 조회가 1.4s 늦게 끝나 이득 일부가 상쇄됐다. 앞당길 때는 무엇이 임계 경로인지 같이 본다.
