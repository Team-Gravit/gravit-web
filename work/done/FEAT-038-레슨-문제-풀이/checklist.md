## 6. 중간에 막혔던 지점

- React 19 타입에서 `FormEvent`가 deprecated되어 제출 핸들러를 `SubmitEvent`로 바꿨다.
- 연속된 주관식 문제가 같은 컴포넌트 인스턴스를 재사용해 입력값이 남았다. `ProblemSolver`에
  `problemId` key를 주어 문제별 상호작용 상태의 수명을 분리했다.
- **객관식에서 「다음 문제」를 누르면 다음 주관식 문제가 건너뛰어졌다.** 브라우저는 클릭 전파를
  끝낸 뒤 버튼의 `type`을 다시 읽는다. 전파 도중 리렌더로 `type`이 `submit`이 되면 그 클릭이
  방금 마운트된 주관식 폼까지 제출했다. `act()`가 리렌더 플러시를 activation behavior 뒤로
  미루기 때문에 **jsdom 테스트로는 재현되지 않았다.** REF-041로 초안을 세션에 올려 DOM을
  뒤지는 통로 자체를 없앴다.
- Vercel 빌드가 `toaster.tsx`에서 `TS2742`로 실패했다. `packages/typescript-config/vite.json`이
  `declaration: true`를 앱까지 물려주고 있었다. pnpm isolated 레이아웃에서는 Radix의 타입 경로를
  선언 파일에 적을 수 없다. 앱 설정에서 선언 생성을 껐다.
- `getByRole('status', { name })`으로 로딩 문구를 찾지 못했다. `role="status"`는
  name-from-content를 지원하지 않는다. `findByText`로 바꿨다.
