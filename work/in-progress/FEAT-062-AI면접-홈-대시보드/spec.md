# FEAT-062 — AI면접 탭 홈 대시보드

GitHub Issue: #310 · 통합 이슈 #270 · 브랜치 `feat/#310/interview-dashboard` → PR 대상 `feat/#270/interview`

## 배경 · 목표

AI면접 탭(`/interview`)은 제목과 「새 세션 시작」 버튼만 있던 임시 화면이었다(#294).
시안 AI-HOME-01의 홈 대시보드로 본문을 교체해, 사용자가 누적 응시 현황과 약점을 한 화면에서 보고
바로 새 세션을 시작할 수 있게 한다.

## 범위

단계별로 진행했다. 1~5단계를 구현했다.

| 단계 | 시안 프레임              | 내용                                                      |
| ---- | ------------------------ | --------------------------------------------------------- |
| 1    | `AI-HOME-01-EMPTY`       | 배너 · 요약 · 세 카드의 빈 상태 + 조회 중 · 실패 상태     |
| 2    | `WEB-AI-HOME-01-DATA1~4` | 약점 정확도 막대 · 최근 응시 이력 목록 · 점수 추이 그래프 |
| 3    | `AI-HOME-01-MODAL`       | 약점 분야 전체 목록 모달                                  |
| 4    | 최근 응시 이력           | 전체 목록 · 정렬 · 페이지 이동                            |
| 5    | 피드백 리포트            | 세션 종합 · 문항별 상세                                   |

## Out of Scope

- 모바일 「전체 점수」 카드의 「전체 보기」 동작 (목적지 미정)
- 만료된 녹음 URL 자동 갱신

## 용어 정의

| 용어      | 정의                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| 대시보드  | `GET /api/v1/interview-sessions/dashboard` 응답(`InterviewDashboardResponse`)   |
| 완료 세션 | 제출과 채점이 끝난 세션. `completedSessionCount`가 센다                         |
| 빈 상태   | 섹션에 표시할 데이터가 없는 상태. 요청 실패(에러)와 구분한다                    |
| 누적 세션 | `completedSessionCount`                                                         |
| 최근 평균 | `recentAverageScore` — 최근 완료 세션 5개 총점 평균. 완료 세션이 0이면 서버가 0 |

## 기술 결정 (ADR)

`feature-planner`를 거치지 않고 GitHub Issue #310으로 범위를 확정했다 (사용자 요청: 이슈 먼저 올리고 진행).
화면 하나를 기존 API·공용 컴포넌트로 조립하는 작업이라 대안 비교가 필요한 결정은 아래 하나다.

**섹션별 조회 vs 페이지 한 번 조회** — 메인 화면처럼 각 카드가 `useInterviewDashboard()`를 직접 호출한다.
같은 queryKey라 요청은 한 번이고, 카드마다 로딩·실패를 독립적으로 표시한다(`CardRetryStatus`).
페이지에서 한 번 받아 props로 내리면 카드가 페이지 상태에 묶여 다른 화면에 재사용하기 어렵다.

시안 웹 ↔ 모바일이 어긋난 항목을 아래로 확정했다.

| #   | 항목                    | 웹                            | 모바일                    | 판정                                   |

| 3   | 배너 설명               | …, 문항으로 점검해요.         | …, 6문항으로 점검해요.    | **모바일** 문구                        |

## 확정 명세 (2단계 — 데이터 있음)

모바일은 데이터 5개 시안만 있다. 사용자 지시(2026-10-18)에 따라 개수별 동작은 웹 DATA1~4와 같게 한다.

| 섹션      | 표시                                                                                                                                     |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 약한 분야 | 주제 표시명 · 「정확도 {accuracyRate}%」 · 정확도만큼 채운 막대. 막대 그라디언트는 전체 폭 기준(빨강→노랑→초록)이라 낮을수록 붉게 남는다 |
| 응시 이력 | 시도 차수 뱃지 · 모드(`CS모드` / `직군모드`) · 「{첫 주제} 외 n개 · M월 D일」(주제 하나면 「외 n개」 없음) · 「{score}점」 칩            |
| 점수 추이 | 0~100점 축, 그리드 3줄. 점 배치 — 1개 가운데 · 2개 1/4 · 3/4 · 3개부터 양 끝 포함 균등. 마지막 점 라벨 「현재」, 나머지 「{sequence}차」 |
| 점수 추이 | 처음엔 「현재」 점수를 말풍선으로 보여주고, 점을 누르면 그 점수로 바뀐다. 웹 헤더에 「클릭 시 상세 점수를 확인할 수 있어요」             |

## 확정 명세 (5단계 — 피드백 리포트, 2026-10-20 사용자 지시)

주소 `/interview/history/$sessionId?tab=summary|answers&question=n`. 응시 이력 페이지와 대시보드 응시 이력 항목을 누르면 이동한다.

| 탭          | 내용                                                                                                                             | API                                    |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| 세션 종합   | 총점 게이지 · 정확도/전달력 점수와 평균 대비 문구 · 최근 5세션 추이선 · 문항별 누적 막대 · 약점 분야 학습 링크                   | `GET /interview-sessions/{id}/summary` |
| 문항별 상세 | 웹 문항 탭 / 모바일 펼치기(한 번에 하나). 질문 · 내 답변 · 녹음 재생 · 모범답안 · 항목별 점수 3칸 막대 · 핵심 개념 · 개선 피드백 | `GET /interview-sessions/{id}/answers` |

- 핵심 개념의 초록 체크는 모든 개념에 똑같이 붙는 아이콘이다 (사용자 확인, 개념별 전달 여부 아님)
- 항목별 점수 3칸 구간은 만점을 3등분해 올림한다 (14 → 5·10·14, 3 → 1·2·3)
- 녹음 재생 URL은 발급 후 30분 유효하다. 만료되면 화면을 다시 열어야 한다
