# MIG-066 — 학습 그만두기 모달 이전

## 배경 · 목표

legacy 레슨 풀이에서는 상단 X 버튼을 누르면 "지금까지 푼 내역이 모두 사라져요!" 확인 모달이 뜬다.
`apps/web`은 이 모달 없이 X를 누르면 바로 풀이를 떠난다. 실수로 누르면 푼 내역을 잃는다.
legacy 동작을 기준으로 모달을 이전하고 Figma 시안과 맞춘다.

## 범위

- 레슨 풀이 화면(`/learning/lessons/$lessonId`)의 X 버튼 → 그만두기 모달
- `widgets/quiz-screen`의 상단바(`QuizTopBar`)와 모달 배치
- 모달 마스코트 이미지 에셋 추가

## Out of Scope

- 북마크 · 오답 풀이의 X 동작 — legacy에서도 모달 없이 바로 떠난다 (기준선 B). 바꿀지는 시안 대조에서 판정한다
- 문제 신고 모달 · 신고 결과 모달 — legacy의 같은 모달 저장소를 쓰지만 별개 기능이다
- 풀이 타이머 · 학습 시간 계산 방식 변경
- 브라우저·기기 뒤로가기로 떠날 때의 확인 처리 (legacy에도 없다)

## 용어 정의 (Ubiquitous Language)

| 용어          | 정의                                                                 |
| ------------- | -------------------------------------------------------------------- |
| 그만두기 모달 | 풀이 중 X 버튼을 누르면 뜨는 확인 모달. "그만두기"와 "계속하기" 버튼 |
| 그만두기      | 모달에서 풀이를 떠나는 선택. 푼 내역은 저장되지 않는다               |
| 계속하기      | 모달만 닫고 풀이를 이어가는 선택                                     |
| 풀이 저장본   | `apps/web`이 새로고침 복원을 위해 저장하는 진행 상태 (legacy에 없음) |

legacy 버튼 변형 이름(`strokeGray`)은 `apps/web`의 `Button` 변형(`stroke-default` 등)과 다르다. 시안 대조에서
변형을 고른다.

## 동일성 확인 방법

- 레슨 풀이 진입 → X → 모달에 제목 · 본문 두 줄씩과 "그만두기" · "계속하기" 버튼이 보인다
- 문제 2개를 풀고 X → "계속하기" → 같은 문제 번호, 입력한 답이 그대로 있다. 바깥 클릭 · Esc도 같다
- 유닛 상세에서 레슨 진입 → X → "그만두기" → 유닛 상세로 돌아간다
- 레슨 URL로 직접 진입 → X → "그만두기" → 유닛 상세로 이동하고, 뒤로가기로 풀이에 다시 들어가지 않는다
- "그만두기" 후 같은 레슨에 다시 들어가면 1번 문제부터 시작한다 (저장본 삭제)
- 기존 테스트: `apps/web`의 상단바 · 떠나기 동작 테스트를 확인해 함께 돌린다

## 기준선을 쓰면서 발견한 것

1. **"자료구조"가 고정 문구다** (C3). 레슨이 어느 챕터든 "자료구조 학습 출제가 중단됩니다."로 나온다. Figma 시안 두 장도 같은 문구다
2. **타이머 일시정지가 apps/web에 없다** (E1 · W4). legacy는 모달이 열려 있는 동안 시간을 멈추고 그만큼 제출 학습 시간에서 뺀다. apps/web은 시작 시각부터 계산해서 멈출 수 없다
3. **apps/web에만 풀이 저장본이 있다** (W3). legacy는 새로고침하면 처음부터였으므로 "모두 사라져요"가 사실 그대로였다. apps/web도 떠나면 저장본을 지우므로 문구와 맞는다
4. **북마크 · 오답 풀이에는 legacy에도 모달이 없다** (B1 · B2). apps/web은 세 풀이가 같은 상단바를 쓰므로, 레슨에만 모달을 띄우려면 상단바가 화면별로 다르게 동작해야 한다

**#1 후속 — 챕터 이름의 출처.** 레슨 문제 응답(`GET /api/v1/problems/{lessonId}` → `LessonResponse`)에는
유닛 정보만 있고 챕터 이름이 없다. 챕터 이름은 유닛 레슨 목록 응답(`GET /api/v1/lessons/{unitId}` →
`LessonDetailResponse.chapterSummary.title`, `entities/learning`의 `useUnitLessons(unitId).chapterTitle`)에 있다.

## 확정 명세 · 검증 기준

> 2026-10-26 판정 기준. 시각 항목(대조 #1 · #3 · #4 · #8)은 테스트가 아니라 Storybook · 실기기 대조로 확인한다.

- [ ] **AC-1** (범위: 통합) 레슨 풀이에서 X를 누르면 모달이 열린다
      Given 레슨 풀이 화면이 열려 있다
      When 상단 X(「풀이 닫기」)를 누른다
      Then 화면을 떠나지 않고 제목 "지금까지 푼 내역이 / 모두 사라져요!"와 「그만두기」 · 「계속하기」 버튼이 있는 대화상자가 열린다
- [ ] **AC-2** (범위: 통합) 본문에 챕터 이름이 들어간다
      Given 레슨이 속한 챕터 이름이 "운영체제"다
      When 그만두기 모달을 연다
      Then 본문이 "운영체제 학습 출제가 중단됩니다." / "정말 학습을 그만두시나요?"다
- [ ] **AC-3** (범위: 통합) 챕터 이름이 없으면 이름만 뺀다
      Given 유닛 레슨 목록 요청이 아직 끝나지 않았거나 실패했다
      When 그만두기 모달을 연다
      Then 본문 첫 줄이 "학습 출제가 중단됩니다."이고 모달은 그대로 열린다
- [ ] **AC-4** (범위: 통합) 「계속하기」 · Esc · 바깥 클릭은 모달만 닫는다
      Given 3번 문제에서 답을 입력한 상태로 모달을 열었다
      When 「계속하기」를 누른다 (Esc · 바깥 클릭도 각각 같다)
      Then 모달이 닫히고 3번 문제와 입력한 답이 그대로 있으며, 경로가 바뀌지 않는다
- [ ] **AC-5** (범위: 통합) 「그만두기」는 지금의 X와 같은 곳으로 떠난다
      Given 유닛 상세에서 레슨으로 들어왔다 (이전 기록 있음)
      When 모달에서 「그만두기」를 누른다
      Then 이전 기록(유닛 상세)으로 돌아간다
- [ ] **AC-6** (범위: 통합) 직접 진입이면 유닛 상세로 기록을 교체한다
      Given 레슨 주소로 직접 들어왔다 (이전 기록 없음)
      When 모달에서 「그만두기」를 누른다
      Then `/learning/units/{unitId}`로 이동하고 현재 기록을 교체한다
- [ ] **AC-7** (범위: 통합) 북마크 · 오답 풀이는 모달 없이 떠난다
      Given 북마크 문제 풀이 또는 오답 문제 풀이 화면이 열려 있다
      When 상단 X를 누른다
      Then 대화상자가 열리지 않고 지금처럼 바로 떠난다
- [ ] **AC-8** (범위: 수동) 시각 항목
      모바일 카드 `bg-0` · 모서리 8px, 데스크톱 카드 `bg-1` · 모서리 12px · `shadow-elevation-1`,
      마스코트 원본 비율(150 / 데스크톱 211 너비), 마스코트 `alt=""`. Storybook과 Figma 두 시안을 나란히 대조한다

「그만두기」 후 풀이 저장본 삭제(계약 C4)는 기존 라우트 `onLeave`가 맡는다. 떠나는 경로가 지금의 X와 같으므로
새 동작이 아니다. AC-5 · AC-6에서 같은 레슨에 다시 들어가 1번 문제부터 시작하는지 수동으로 함께 본다.
