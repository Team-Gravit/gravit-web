# FIX-053 — 메인 화면 시안 대조 수정과 태블릿 폭 반응형

GitHub Issue #280 · 브랜치 `fix/#280/main-page`

## 배경 · 목표

메인 화면(`/main`)의 시안 차이 5건과 태블릿 폭(약 768~911px)에서 겹치는 레이아웃을 한 번에 고친다.
v2 첫 출시 범위다.

메인은 화면 폭에 따라 레이아웃을 통째로 고른다 — `pages/main/ui/main-page.tsx` 가
`MainPageWide`(md 이상) / `MainPageNarrow` 중 하나를 그린다.

## 판정 (2026-10-08, 사용자)

| #   | 판정                                                                                                                                                                                                                                                                                                                                                     |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | 히어로 — 배경은 CSS 그라데이션 + 장식 이미지로 분리. 그라데이션은 시안 `linear-gradient(-57deg, #4721CA 3.59%, #17034E 95.08%)`(`13750:50583`). 장식 이미지는 Codex 워크트리 `gravit-main-bg-asset` 의 `main-mobile-decoration.png`(720×532, 16-bit PNG 297KB → webp 변환 필요). **넓은 화면은 사용자가 검토 후 결정 — 이번 커밋에서 보류**              |
| 2   | 문구 — 칩 문구는 시안과 같다. 단 「잠김」은 잠금 개념이 없어 **레슨 목록(`LessonItem`)과 같이 「학습 전」**. API `NOT_STARTED` → 상태 `notStarted` (기존 `locked` 는 이름이 틀렸다)                                                                                                                                                                      |
| 3   | 알림 — 시안 `communication/line/bell` 24px 를 LV · 티어 줄 오른쪽 끝에. 누르면 `/notifications`                                                                                                                                                                                                                                                          |
| 4a  | 성장 현황 — `lg`(1024px) 미만에서 LV 게이지와 티어 게이지를 세로로 쌓는다 · 두 게이지 머리 줄 높이를 맞춘다 — `TierBadge`(`inline-flex`)를 감싼 `div` 를 `flex` 로 바꿔 글자 줄 여유 높이를 없앰                                                                                                                                                         |
| 4b  | 이어서 학습하기 — **칩 폭 고정**(`min-w-20`, 가장 긴 「학습 완료」 기준). 제목은 기존처럼 말줄임 · **원인은 말줄임이 동작하지 않던 것** — 제목을 감싼 `span` 에 `min-w-0` 이 없어 제목 길이만큼 행 밖으로 넘쳤다. `min-w-0` 추가로 해결                                                                                                                  |
| 5   | 새 주제 시작하기 — 데이터부터 달랐다(모바일: 최근 학습 첫 유닛 · 데스크톱: 추천 유닛). **데스크톱 기준**으로 모바일도 추천 유닛을 쓰고 첫 항목 하나만 (`RecommendedUnitCard`). `RecentUnitCard` 제거 · 행성 크기를 넓은 화면도 카드 **높이** 기준(`md:h-4/5`)으로 — 카드 높이는 고정이고 너비만 변해 너비 기준이면 크기가 들쭉날쭉했다. 시안도 높이 비율 |
| 6   | 연속 학습일 「자세히 보기」 → `/my/learning`                                                                                                                                                                                                                                                                                                             |
