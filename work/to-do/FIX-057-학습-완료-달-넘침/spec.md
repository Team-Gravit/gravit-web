# FIX-057 — 학습 완료 화면에서 장식 달이 넘쳐 세로 스크롤이 생김

GitHub Issue #302 · 브랜치 `fix/#302/lesson-result-overflow`

> iPhone Safari 레이아웃 조사(2026-10-13)의 수정 6단계 중 **2단계**다. 1단계는 `FIX-055`(#300).
> 전체 그림과 용어는 `local-docs/문서/safari-스크롤/쉬운-설명.html` 그림 4.

## 배경 · 목표

좁은 화면의 학습 완료 화면을 스크롤하면 마스코트 위쪽이 잘리고, 버튼 아래로 큰 달과 배경이
길게 이어진다. 장식 달이 페이지 경계에서 잘리지 않고 스크롤 범위를 만들고 있다.
달은 페이지 경계에서 잘리고, 결과 내용과 버튼은 지금처럼 모두 닿을 수 있게 한다.

## 관찰 (배포 버전, iPhone Safari)

| 캡처        | 보인 것                                                                                   |
| ----------- | ----------------------------------------------------------------------------------------- |
| `_03` 10:23 | 마스코트 위쪽이 잘림. 버튼 아래로 달이 화면 높이 절반 넘게 이어짐. 오른쪽에 스크롤바 표시 |

상태바 아래가 흰 띠로 깔끔하게 끊겨 있다. 바깥 문서가 아니라 페이지 루트 안쪽이 스크롤된 모습이다.

## 원인 (코드로 확정)

- 페이지 루트 `div[data-slot="lesson-result-page"]` — `relative isolate flex min-h-dvh flex-col` +
  `bg-space-gradient overflow-x-hidden` (`pages/lesson-result/ui/lesson-result-page.tsx`)
- CSS 규칙상 한 축이 `hidden`이고 다른 축이 `visible`이면 `visible`은 `auto`로 계산된다.
  그래서 `overflow-x-hidden`만 지정한 루트가 **세로 스크롤 컨테이너**가 된다
- 달 `div[data-slot="mobile-moon"]`(`pages/lesson-result/ui/result-hero.tsx`)은 `absolute`,
  너비 `138vw`, 일러스트 상자의 `top: 83.33%`에서 시작해 루트 아래로 넘친다. 이 넘친 영역이 루트의
  스크롤 범위가 된다
- 배경 `div[data-slot="result-background"]`의 `overflow-hidden`은 달을 자르지 못한다. 달이 그 자식이 아니다

## 범위

| 파일                                            | 변경                                                           |
| ----------------------------------------------- | -------------------------------------------------------------- |
| `pages/lesson-result/ui/lesson-result-page.tsx` | 성공 화면 루트의 `overflow-x-hidden` → `overflow-clip` (두 축) |

`overflow: clip`은 스크롤 컨테이너를 만들지 않는다. 루트는 in-flow 콘텐츠만큼 늘어나므로 내용이 화면보다
길면 바깥 문서가 스크롤되고, 달만 루트 경계에서 잘린다. iOS Safari 16부터 지원한다.

`overflow-x-clip`만 쓰면 세로가 `visible`로 남아 달이 바깥 문서를 늘린다. 두 축 모두 지정한다.

## Out of Scope

- 장식 레이어(배경 · 달)와 콘텐츠 레이어의 구조 분리
- 달 크기 · 위치 등 시안 수치 조정
- 데스크톱 결과 화면 — 달을 그리지 않는다(`isWideViewport`)
- 오류 화면 분기 — 달을 그리지 않는다
- 3~6단계 (튕김 · 키보드 · 단위 정리 · 문서 배경)
