# REF-071 — 첫 청크에 남은 로고 · 알림 팝오버 · 퀴즈 세션 코드 정리

관련: REF-063(#312) · REF-062(#313)

## 배경 · 목표

REF-063 이후 첫 청크(`index-*.js`)는 518,842 B다. 대부분은 모든 화면이 쓰는 라이브러리와 앱 셸이지만,
첫 그리기에 필요 없거나 필요 이상으로 큰 앱 코드가 세 묶음 남아 있다. 받는 양과 파싱 양을 줄인다.

REF-063에서 gzip 약 45 KiB를 줄여도 FCP·LCP는 흔들림 안이었다. 이 작업도 체감 속도보다 **받는 양 정리**가 목표이며,
LCP 병목(API 요청 순서)을 다루는 REF-062보다 우선순위가 낮다.

## 현행 기준선 (2026-10-29, `perf/#312/entry-chunk-quiz-icons` 빌드)

근거: `local-docs/performance/evidence/2026-10-29_bundle_visualizer_312-after.html` (로컬 전용).
크기는 번들 지도의 모듈별 값(압축 전 · gzip 추정)이다. 실제 파일 크기와 다르므로 비교에만 쓴다.

첫 청크 구성(압축 전 비율): react-dom 41% · TanStack Router 13% · axios 12% · tailwind-merge 8% · TanStack Query 5% · 앱 코드 약 13%.

| 1. 로고 SVG          | `shared/ui/logo` (`logo-gradient.svg` 13,608 B · `logo-mono.svg` 11,743 B)                                                                               | 27.7 KB / 11 KB     | SVG를 React 컴포넌트로 넣어 두 변형이 항상 함께 실린다. 앱 셸의 헤더(모바일에서는 숨김)·푸터가 사용                                                                                            |

| 3. 퀴즈 세션 context | `features/lesson-quiz/model`                                                                                                                             | 10 KB / 3 KB        | 라우트 설정(`-review-quiz-route.ts` · `learning.lessons.$lessonId.tsx`)이 배럴에서 `clearStoredQuizSession`을 가져온다. `createContext` 호출이 부수 효과로 판단돼 남는다 (REF-063 spec `결과`) |

## 범위

- 위 세 후보를 첫 청크에서 빼거나 줄인다. 방법은 계획 단계에서 비교한다
  - 1: SVG를 URL(`<img>`)로 쓰기 · SVG 최적화 · 사용하는 변형만 import
  - 2: 팝오버 내용 지연 로딩
  - 3: 라우트 설정이 가져오는 함수의 위치 이동 또는 `sideEffects` 선언
- 전후 첫 청크 크기와 FCP·LCP 측정 (녹화 응답 재생, REF-063과 같은 조건)

## Out of Scope

- react-dom · axios · TanStack · tailwind-merge 교체
- 라우트 데이터 미리 요청 (REF-062)
- 이미지 로딩 방식 (REF-054)
- 로고·알림 화면의 모양·동작 변경

## 확인 필요

1. 로고를 `<img>`로 바꾸면 `currentColor` 같은 색 제어가 필요한 곳이 있는지 (단색 로고 사용처 확인)
2. 알림 팝오버를 지연 로딩할 때 처음 열 때의 대기를 어떻게 보여 줄지 — 시안에 로딩 상태가 없으면 디자이너 확인
