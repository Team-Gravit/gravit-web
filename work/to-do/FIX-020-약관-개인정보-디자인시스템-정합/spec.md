# FIX-020 — 약관·개인정보 화면 디자인 시스템 정합

## 배경 · 목표

`/terms`와 `/privacy`는 시안 없이 급하게 만든 화면이다(MIG-004). 내용은 확정본이지만 표현이
디자인 시스템을 따르지 않는다. `MIG-018`에서 로그인 화면이 이 두 화면으로 링크를 걸게 되어
사용자가 실제로 도달하므로, 표현을 토큰 기반으로 맞춘다.

**내용은 그대로 둔다.** 조항 순서·문구·개수를 바꾸지 않는다.

## 현재 상태 (2026-09-09 확인)

| 항목        | 현재                                 | 있어야 할 것                            |
| ----------- | ------------------------------------ | --------------------------------------- |
| 제목 타이포 | `text-2xl font-bold`                 | 타이포 토큰 (`text-title1` 등)          |
| 절 제목     | `text-xl font-semibold`              | 타이포 토큰 (`text-heading1` 등)        |
| 본문 타이포 | 지정 없음 (브라우저 기본)            | 타이포 토큰 (`text-body1-normal` 등)    |
| 글자색      | 지정 없음                            | 색 토큰 (`text-text-1` ~ `text-text-4`) |
| 여백        | `px-8 py-12` 고정                    | 좁은 화면 대응                          |
| 본문 폭     | `max-w-[800px]`                      | 유지 여부 판정                          |
| 헤더        | `px-8 py-4` · `bg-white` · `z-[110]` | 토큰과 레이아웃 규칙 확인               |

확인한 위치: `apps/web/src/pages/terms/ui/terms-page.tsx` ·
`apps/web/src/pages/privacy/ui/privacy-page.tsx`

## 범위

- `pages/terms/ui/terms-page.tsx` — 타이포·색 토큰 적용, 좁은 화면 대응
- `pages/privacy/ui/privacy-page.tsx` — 〃
- 두 화면이 같은 구조를 반복하므로 공통 문서 레이아웃 추출 여부를 착수 시 판단한다
  (`refactor-checklist.md`의 공통화 판단 — 2번 등장은 인라인, 3번째에 추출)

## Out of Scope

- **문구·조항 내용 변경** — 법적 문서다. 표현만 바꾼다
- **`widgets/footer`의 미확정 토큰** — `FIX-009`가 담당한다
- **새 토큰 추가** — `tokens.css`에 있는 것만 쓴다. 부족하면 `확인 필요`로 남긴다

## 확인 필요

- **시안이 없다.** `design-source-policy.md` §7에 따라 「시안 없음(2026-09-09 확인)」을 명시하고,
  기존 토큰 안에서 가장 가까운 값을 고른다. 개선 판단(레이아웃 재설계)은 하지 않는다
- 본문 최대 폭 `800px`을 유지할지 — 토큰이 아니라 임의값이다

## 확정 명세 · 검증 기준

- [ ] **AC-1** (범위: 통합)
      Given `/terms`가 렌더되어 있다
      When 제목과 조항 제목의 클래스를 확인한다
      Then `text-2xl` · `text-xl` · `font-bold` · `font-semibold`가 하나도 없다

- [ ] **AC-2** (범위: 통합)
      Given `/privacy`가 렌더되어 있다
      When 제목과 절 개수를 확인한다
      Then 제목이 「개인정보 처리방침」이고 절이 **9개**다 (MIG-004의 기존 테스트와 동일)

- [ ] **AC-3** (범위: 통합)
      Given `/terms`가 렌더되어 있다
      When 제목과 조항 개수를 확인한다
      Then 제목이 「서비스 이용약관」이고 조항이 **13개**다 (MIG-004의 기존 테스트와 동일)

> AC-2·AC-3은 표현만 바꾸고 **내용은 안 바뀌었음**을 고정한다. MIG-004가 남긴 테스트가 이미 있다.
