# FIX-067 — 그만두기 모달이 열린 동안 풀이 타이머 멈춤

## 배경 · 목표

legacy 레슨 풀이는 그만두기 모달이 열려 있는 동안 상단 타이머를 멈추고, 그 시간을 제출 학습 시간에서 뺐다.
`apps/web`은 세션 시작 시각부터 흐른 시간으로 타이머와 학습 시간을 계산해서 멈출 수 없다.
MIG-066에서 모달을 이전하면서 이 동작은 "나중"으로 판정해 이 항목으로 분리했다 (MIG-066 `spec.md` 확인 필요 #2).

## 재현

1. 레슨 풀이에 들어가 X를 눌러 그만두기 모달을 연다 (MIG-066 이후)
2. 1분 기다린 뒤 「계속하기」를 누른다
3. 타이머가 모달이 열려 있던 1분을 포함해 흘러 있다. 제출 학습 시간에도 1분이 들어간다

legacy에서는 같은 순서로 타이머가 모달을 열기 전 값에서 이어진다.

## 원인

| 위치 (`apps/web/src`)                       | 내용                                                            |
| ------------------------------------------- | --------------------------------------------------------------- |
| `widgets/quiz-screen/ui/quiz-timer.tsx`     | 표시 시간 = 현재 시각 − `startedAt`                             |
| `pages/lesson-quiz/ui/lesson-quiz-page.tsx` | 제출 `learningTime` = 현재 시각 − `startedAt`                   |
| `features/lesson-quiz/model/` (세션)        | `startedAt`은 새로고침 후에도 유지되도록 풀이 저장본에 들어간다 |

멈춘 시간을 빼려면 멈춘 구간의 합(또는 멈춘 시각)을 세션에 함께 저장해야 한다. 새로고침 복원과 같이 맞춰야 한다.

## 범위

- 풀이 중 모달(그만두기 · 문제 신고 작성 · 신고 성공)이 열린 동안 타이머 표시와 제출 학습 시간을 멈춤
- 풀이 저장본의 시간 필드

## Out of Scope

- 모달 자체 (그만두기 MIG-066 · 문제 신고 MIG-068)

## 확인 필요

1. 모달 말고도 멈춰야 하는 경우가 있는가 (예: 앱이 백그라운드로 갔을 때)
2. 새로고침으로 복원했을 때 모달이 열린 채였다면 멈춘 시간을 어떻게 셀 것인가
