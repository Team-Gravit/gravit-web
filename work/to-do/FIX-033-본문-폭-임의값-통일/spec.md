# FIX-033 — 본문 폭 임의값 통일

## 배경

`MIG-030` 검증 중 학습 영역 화면들의 본문 컨테이너를 대조하다 발견했다.
**같은 1200px 인데 표기가 두 가지**다.

| 화면      | 표기             | 파일                                        |
| --------- | ---------------- | ------------------------------------------- |
| 메인      | `max-w-[1200px]` | `pages/main/ui/main-page-wide.tsx`          |
| 학습 홈   | `max-w-300`      | `pages/learning/ui/learning-page-wide.tsx`  |
| 유닛 상세 | `max-w-300`      | `pages/unit-detail/ui/unit-detail-page.tsx` |

`max-w-300` 은 spacing 스케일 300 × 4px = 1200px 로 값이 같다.

## 왜 고쳐야 하나

지금은 화면이 똑같이 보이므로 버그가 아니다. **문제는 나중에 생긴다.**

본문 폭을 조정할 일이 생기면 `max-w-300` 을 검색해 고치게 되고 메인만 빠진다. 반대로
`1200px` 을 검색해도 나머지가 빠진다. **어느 쪽으로 검색해도 전부를 찾을 수 없는 상태**다.

`className-convention.md` §4 가 임의값 대신 토큰 클래스를 쓰라고 하는 이유가 이것이다.

## 범위

- `main-page-wide.tsx` 의 `max-w-[1200px]` → `max-w-300`
- 같은 종류의 임의 폭이 더 있는지 검색해 함께 정리

```bash
rg -n "max-w-\[|w-\[[0-9]+px\]" apps/web/src --glob '*.tsx'
```

## Out of Scope

- **좌우 여백 규칙 통일** — 학습 홈이 `px-4.5`(18px)로 다른 화면(`px-8`, 32px)과 다르지만
  `카드 그리드의 안쪽 여백`이라는 근거가 주석에 남아 있다. 의도된 차이이므로 건드리지 않는다
- 본문 폭 값 자체의 변경

## 검증

메인 화면이 넓은 화면에서 이전과 같은 폭·같은 위치로 보이는지 확인한다.
값이 같으므로 시각적 변화가 없어야 한다 — **변화가 보이면 무언가 잘못된 것이다.**
