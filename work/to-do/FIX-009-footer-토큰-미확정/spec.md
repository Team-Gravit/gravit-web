# FIX-009 — Footer 시안 대조에서 남은 판정 3건

## 배경 · 목표

`#190`(약관·개인정보 이전)의 Footer 를 Figma 시안과 대조해 구조·토큰·순서를 맞췄다.
그 과정에서 **임의로 결정하면 안 되는 것 3건**이 남았다 (`design-source-policy.md` §5).

근거: Figma `W/푸터` [`11712:27415`](https://www.figma.com/design/hu4c6qCEMB62qHXk2v8Gsl/-New-Gravit?node-id=11712-27415)

## 범위

- `apps/web/src/widgets/footer/ui/footer.tsx`
- 필요 시 `apps/web/src/app/styles/tokens.css` (별칭 토큰 추가)
- 필요 시 `apps/web/src/widgets/footer/ui/assets/logo-appcenter.png` 교체

## Out of Scope

- Footer 외 화면
- 호환 토큰 51개 전체 제거 (별개 작업)

## 시안 대조 결과

### 이미 맞춘 것 (#190 에서 처리)

| 항목        | 조치                                                                  |
| ----------- | --------------------------------------------------------------------- |
| 배경색      | `bg-gray-700`(#5a5a5a, 호환 토큰) → `--primitive-gray-700`(#666666)   |
| 본문 타이포 | `text-xs`(12px) → `text-body1-normal`(16/1.5/400)                     |
| 순서        | `Powered by` 를 주소·문의 메일 **아래**로                             |
| 저작권 문구 | `Copyright 2026. Gravit! All rights reserved.` 추가 (우측 정렬)       |
| 구분선      | 1개 → **2개** (로고 아래 · 본문 아래), `white/45`                     |
| 세로 구분선 | 로고 사이에 추가, `border-divider-2`(#c6c6c6)                         |
| 여백        | `px-[150px]` · `pt-[50px]` · `pb-[100px]`                             |
| 로고 색     | `brightness-0 invert` 제거 → `text-text-1-w` (mono 가 `currentColor`) |

### 판정 필요

| #   | 항목               | 현행                          | 시안                  | 판정 |
| --- | ------------------ | ----------------------------- | --------------------- | ---- |
| 1   | 약관·개인정보 링크 | 있음                          | **없음**              |      |
| 2   | 배경색 별칭 토큰   | `--primitive-gray-700` 직참조 | `Gray Scale/Gray_700` |      |
| 3   | 앱센터 로고 에셋   | 671×181 PNG 를 크롭해 사용    | 194×36 으로 잘라 씀   |      |

### 확인 필요

- **#1 약관·개인정보 링크를 지울 것인가** — 시안에 없다. 다만 **약관·개인정보 화면으로 가는
  유일한 경로**라 지우면 사용자가 그 페이지에 도달할 수 없다. 시안의 누락인지 의도인지 확인이 필요하다.
  시안 하단에 `pb-[100px]` 만큼 빈 영역이 있어 **링크 자리가 비어 있는 것**일 수도 있다
- **#2 배경색 별칭 이름** — `tokens.css` 에 #666666 에 대응하는 `--color-*` 별칭이 없다.
  `--primitive-gray-700` 만 있어서 Tailwind 유틸리티가 생성되지 않아 `bg-[var(--primitive-gray-700)]`
  로 우회했다. **별칭 이름은 디자인 결정이라 임의로 짓지 않았다.** (`--color-bg-5`? `--color-bg-dark`?)
  → 시안의 텍스트 색이 `rgba(255,255,255,0.58)` · `0.8` 처럼 **토큰이 아닌 원시값**이라는 점도 함께 본다
- **#3 앱센터 로고 여백** — 원본 PNG(671×181) 위아래에 여백이 있어 시안이 194×36 으로 크롭해 쓴다.
  구현도 크롭을 재현했으나 퍼센트 값이 코드에 박힌다. **여백을 제거한 에셋으로 교체하면 사라진다**

## 확정 명세 · 검증 기준

> 아래 AC는 판정 결과를 구현할 때 적용한다. #1·#2·#3의 제품·디자인 결정 전에는 구현하지 않는다.

- [ ] **AC-1** (범위: 단위)
      Given #1 이 `지움` 으로 확정된 경우
      When Footer 를 렌더한다
      Then `개인정보 처리방침` · `서비스 이용약관` 링크가 문서에 없다
- [ ] **AC-2** (범위: 단위)
      Given #2 별칭 토큰이 확정된 경우
      When `tokens.css` 를 확인한다
      Then 그 별칭이 `--primitive-gray-700` 을 참조하고, Footer 가 `bg-[var(...)]` 대신 별칭 유틸리티를 쓴다
- [ ] **AC-3** (범위: 통합)
      Given #3이 `여백 제거 에셋으로 교체`로 확정된 경우
      When Footer를 렌더한다
      Then 앱센터 로고가 퍼센트 기반 크롭 없이 확정된 표시 크기와 비율로 렌더된다
