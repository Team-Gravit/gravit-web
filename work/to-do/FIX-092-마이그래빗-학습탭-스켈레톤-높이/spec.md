# FIX-092 — 마이그래빗 학습 탭 첫 카드 스켈레톤이 실제보다 약 36px 작음

## 배경 · 목표

마이그래빗 학습 탭(`/my/learning`)에서 첫 카드(일별 완료 레슨)의 스켈레톤이 실제보다 약 36px 작아 두 번째 카드가 밀린다(`performance/real-env/results/REPORT.md` §3-③).
두 번째 카드가 대부분 화면 밖이라 CLS는 0.002(좋음)다. 눈에 띄는 정도는 작아 우선순위가 낮다.

## 재현

모바일 웹 · 스텁 응답 600ms로 `/my/learning`을 시간 순으로 찍는다(`cls-probe/film_my_learning/`).
0.9초 스켈레톤 첫 카드 아래 끝 y≈732 → 2.4초 실제 y≈768.

## 범위

- `pages/my`의 학습 탭 스켈레톤 높이

## Out of Scope

- 학습 탭 그래프 · 문구 변경

## 확정 명세 · 검증 기준

- [ ] **AC-1** (범위: 통합)
      Given 모바일 웹 · 스텁 응답 600ms
      When `/my/learning`을 시간 순으로 찍는다
      Then 첫 카드의 스켈레톤과 실제 높이 차이가 4px 이하다
