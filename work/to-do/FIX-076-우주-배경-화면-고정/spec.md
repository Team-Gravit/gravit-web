# FIX-076 — 우주 배경을 화면에 고정

GitHub Issue: 미등록

## 배경 · 목표

우주 배경(`shared/ui/layout/space-background.tsx`)은 콘텐츠 상자 전체에 깔려 같이 스크롤된다. 콘텐츠가 길면 상자도 길어지고 `cover`가 높이에 맞춰 이미지를 키워서, 같은 화면이라도 페이지 길이 · 기기에 따라 별 크기가 달라진다.

- 위아래 경계를 없앤 반복 이미지(A)와 배경 고정(B)을 비교했고, **디자이너 제안대로 B(화면 고정)**로 간다(2026-10-30)
- 배경은 화면에 고정되고 콘텐츠만 그 위를 지나간다. 배경은 한 화면만 덮으면 되므로 기기에 맞는 작은 파일을 고를 수 있다(REF-054 #356에서 못 한 부분)

## 범위 (2026-10-30 디자이너 · 사용자 확인)

- **적용 화면 — 모두:** starfield 변형 4곳(개념 노트 넓은 · 챕터 목록 좁은 · 넓은 · 유닛 상세) + 기본 변형 4곳(로그인 넓은 · 온보딩 넓은 · 온보딩 완료 넓은 · 모달)
- **기준 위치 — 위쪽:** 화면 비율이 달라도 이미지 위쪽 구도가 먼저 보인다(`object-top`)
- **이미지 — 구성은 같고 크기만 다른** 모바일용 · 데스크톱용을 디자이너에게 받는다

## 구현 방향 (초안)

- 이미지를 `position: fixed; inset: 0` 상자에 `object-cover object-top`으로 깐다. `background-attachment: fixed`는 iOS Safari에서 동작하지 않고 스크롤마다 다시 그려 쓰지 않는다
- 화면을 움직이는(transform) 상자 안에 있으면 `fixed`가 화면이 아니라 그 상자 기준이 된다. `PullToRefresh` 같은 상자 **밖**에 둔다 — 리그 배경(`pages/league/ui/league-page.tsx`)이 이미 이 방식이다
- 화면 크기 기준이라 `srcset` + `sizes="max(100vw, …vh)"`로 기기에 맞는 파일을 고른다
- 모달은 화면 전체가 아니라 모달 상자 안 배경이라 `fixed` 대상이 아닐 수 있다 — 착수 때 확인

## 순서 · 겹치는 작업

- REF-054 #356(starfield `<picture>`, PR #367) 머지 뒤에 한다
- **FIX-073 Issue 1(#357)도 기본 우주 배경을 새 시안(그라데이션 + 투명 장식)으로 바꾼다.** 같은 파일 · 같은 화면이라 둘 중 무엇을 먼저 할지, 또는 합칠지 정해야 한다

3. 모달 배경도 고정 대상인지
