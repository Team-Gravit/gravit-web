# FIX-019 — 소셜 로그인 버튼 연타 방지

## 배경 · 목표

legacy와 `MIG-018`의 소셜 로그인 버튼은 인가 URL 조회 중에 아무 표시도 하지 않고 버튼도
비활성화하지 않는다. 버튼을 연타하면 **누른 횟수만큼 조회 요청이 나간다.**

MIG-018은 legacy 동작을 보존하는 이전 작업이라 이 결함을 그대로 옮겼다. 여기서 고친다.

## 재현

1. `/`로 진입한다
2. 「카카오로 시작하기」를 빠르게 3회 클릭한다
3. 네트워크 탭에 인가 URL 조회 요청이 3건 나간다

## 원인

`useOauthLogin()`의 `mutate`만 호출하고 `isPending`을 쓰지 않는다. 성공 시
`window.location.href` 전환이 일어나기 전까지 버튼이 계속 눌린다.

## 범위

- `features/auth-login/ui/social-login-button.tsx` — `isPending` 동안 버튼 비활성

## Out of Scope

- **실패 시 사용자 알림** — `FEAT-017`이 담당한다
- **시각 디자인 결정** — 시안에 로딩 상태 프레임이 없다. 스피너를 새로 그리지 않고
  기존 `Button`의 로딩 표현을 쓰거나, 비활성만 적용할지 착수 시 판정한다

## 확정 명세 · 검증 기준
