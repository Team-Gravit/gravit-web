# FIX-007 — 색 토큰 5건을 Figma 칩 기준으로 맞춤 (디자이너 확인 대기)

## 배경 · 목표

디자이너의 **Alias Token 페이지**(`8240:13750`)와 `tokens.css`를 대조해 색 토큰 5건을 맞췄다.
**적용은 끝났고, 이 항목은 디자이너 확인을 받기 위한 것이다.**

근거: [Alias Token](https://www.figma.com/design/hu4c6qCEMB62qHXk2v8Gsl/-New-Gravit?node-id=8240-13750)

## 적용한 변경

| 토큰         | 이전      | 이후          | 참조 변경                    |
| ------------ | --------- | ------------- | ---------------------------- |
| `main`       | `#BE21FF` | **`#BA00FF`** | `purple-500` → `purple-600`  |
| `icon-color` | `#BE21FF` | **`#BA00FF`** | `purple-500` → `purple-600`  |
| `bg-1`       | `#FFFFFF` | **`#F8F8F8`** | `gray-0` → `gray-100`        |
| `text-2-w`   | `#F2F2F2` | **`#DCDCDC`** | `gray-200` → `gray-300`      |
| `success`    | `#00C30D` | **`#4CAF50`** | 원시값 (대응 primitive 없음) |

적용 후 재대조: **29건 전부 일치.**

## ⚠️ 왜 "칩" 기준인가

Alias Token 페이지에는 **손으로 타이핑한 hex 텍스트**와 **변수에 바인딩된 색상 칩**이 함께 있는데
**셋이 어긋나 있었다.**

| 토큰         | 문서 텍스트 | 실제 칩     |
| ------------ | ----------- | ----------- |
| `bg-1`       | #FFFFFF     | **#F8F8F8** |
| `success`    | #00C30D     | **#4CAF50** |
| `icon-color` | #BE21FF     | **#BA00FF** |

칩이 변수에 묶여 있으므로 **칩의 바인딩 값 = 현재 값**으로 판정했다. 색상은 스크린샷 픽셀값이
아니라 Figma 노드·변수 메타데이터를 근거로 확인하고, 화면(WEB·AOS)은 교차 확인에만 사용한다.

## 확인 필요 — 디자이너께

- **① 브랜드 메인이 `#BA00FF`로 바뀐 것이 맞는가** — `main`·`icon-color` 2건이 함께 움직였다
- **② `bg-1`이 `#F8F8F8`인가** — 과거 `fe6b675 fix(web): bg-1 토큰을 디자인 값 #FFFFFF로 수정 (#176)`
  커밋이 있다. **그때 낡은 hex 텍스트를 보고 고쳤을 가능성**이 있어 확인이 필요하다
- **③ `success`가 `#4CAF50`인가** — Material 초록으로 바뀐 것으로 보인다
- **④ `text-2-w`가 `#DCDCDC`인가**
- **⑤ Alias Token 페이지의 hex 텍스트를 칩과 맞춰줄 수 있는가** — 지금 3곳이 어긋나 읽는 사람이 헷갈린다
- **⑥ spacing · shadow 토큰을 정의할 계획이 있는가** — 현재 디자인 시스템에 없다.
  없으면 spacing 은 Tailwind 기본 스케일을 쓰고 그림자는 추가하지 않는다

## Out of Scope

- 호환 토큰 51개 제거 (별개)
- radius — **디자인 시스템에 없고 DX를 위해 우리가 정한 체계다**
- 화면 구현 수정 — 토큰만 바꿨다
