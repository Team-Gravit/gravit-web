# REF-061 — PageHeader와 PageTitleBar 통합 검토

## 배경 · 목표

좁은 화면의 상단 막대가 두 벌 있다. 높이 48px, 아래 테두리, 가운데 `h1` 제목(`text-label1 text-text-2`)까지
겉모습이 같다. FEAT-060에서 상태 표시줄 여백을 넣을 때 같은 수정을 두 곳에 해야 했다. 한쪽만 고치면
화면마다 상단이 달라진다.

합칠 수 있는지 판단하고, 합친다면 동작을 바꾸지 않고 하나로 만든다.

## 현황

| 항목      | `PageHeader` (`shared/ui/layout`)                           | `PageTitleBar` (`widgets/page-title-bar`)               |
| --------- | ----------------------------------------------------------- | ------------------------------------------------------- |
| 스크롤    | 함께 올라간다                                               | `sticky top-0 z-50`                                     |
| 배경      | 없음                                                        | `bg-white`                                              |
| 왼쪽      | `leftSlot`에 아무 요소                                      | `backTo`·`backIcon`으로 뒤로/닫기 링크를 직접 만든다    |
| 뒤로 가기 | 호출부가 정한다                                             | 방문 기록이 있으면 뒤로, 없으면 `backTo`로 이동         |
| 오른쪽    | 없음                                                        | `rightSlot`                                             |
| 사용처    | 로그인, 온보딩, `DocumentLayout`(이용약관·개인정보처리방침) | 학습, 챕터, 유닛 상세, 개념노트, 친구, 알림, 설정, 문의 |

`widgets/quiz-screen/ui/quiz-top-bar`도 같은 겉모습이다. 닫기 링크 · `md:h-16` · 넓은 화면에서도 쓰는 점이 다르다.

## 범위

- 두 컴포넌트(필요하면 `QuizTopBar` 포함)를 하나로 합칠지 판단
- 합친다면 겉모습은 `shared`에, 라우터 방문 기록을 쓰는 뒤로 가기는 별도로 두는 구조 검토
  (예: 공용 틀 + `widgets`의 뒤로 가기 링크를 `leftSlot`으로 주입)

## Out of Scope

- 상단 막대의 시각 변경 (높이·색·타이포)
- 넓은 화면 헤더(`widgets/header`)
- 온보딩 취소·약관 `onBack` 같은 화면별 뒤로 가기 동작 변경

## 확인 필요

- `PageHeader` 화면(로그인·온보딩·약관)에 sticky를 적용해도 되는가. 지금은 함께 스크롤된다.
  합치면서 동작이 바뀌면 구조 변경이 아니므로 `FIX-`로 분리한다
- Figma에서 두 막대가 같은 컴포넌트인지

## 동작 고정 수단

`page-title-bar.test.tsx`가 뒤로 가기 분기를 고정하고 있다. `PageHeader`는 테스트가 없으므로
착수 시 사용처 4곳의 제목·왼쪽 조작을 기준선으로 기록한다.
